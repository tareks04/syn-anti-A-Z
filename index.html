ব্যবহারবিধি

১. হাতে শব্দ যোগ: Main Word লিখুন, তারপর comma দিয়ে একাধিক synonym ও antonym লিখে সংরক্ষণ করুন।

২. TXT / JSON Import: .txt ফাইল থেকে শব্দের তালিকা অথবা JSON Export করা ব্যাকআপ আপলোড করুন। এরপর “টেক্সট বিশ্লেষণ করুন” চাপুন, Preview দেখে Import করুন। JSON ব্যাকআপে learning progress থাকলে সেটিও restore হবে।

৩. MCQ: পরীক্ষার ধরন ও প্রশ্নসংখ্যা বেছে Start চাপুন। একটি উত্তর বেছে নিলেই সঙ্গে সঙ্গে সঠিক/ভুল দেখাবে। উত্তর দেওয়ার পর মূল শব্দসহ চারটি অপশনের English-Bangla.com অভিধান খোলা যাবে। প্রতিটি শব্দের পাশের নিচের তীর চাপলে তার অভিধান খুলবে বা বন্ধ হবে—নতুন ট্যাব খুলবে না; উত্তর দেওয়ার পর সাইট স্বয়ংক্রিয়ভাবে অভিধান অংশে স্ক্রল করবে। আগের প্রশ্ন বাটনে আগের প্রশ্নে ফিরে উত্তর দেখতে পারবেন; পরের প্রশ্নে যেতেও পারবেন বা প্রশ্ন বাদ দিতে পারবেন।

৪. অটো Synonym/Antonym: ইন্টারনেট থাকলে Datamuse থেকে সম্ভাব্য synonym/antonym খোঁজা যায়; ফলাফল যাচাই করে সংরক্ষণ করুন।

৫. পুনরাবৃত্তি: ভুল হওয়া প্রশ্ন বারবার আসবে। ভুল প্রশ্ন টানা ৪ বার সঠিক করলে সেটি Corrected হিসেবে চিহ্নিত হবে। প্রতি ১০ প্রশ্নে লক্ষ্য অনুপাত New:Corrected:Mistaken = ৪:১:৫; কোনো শ্রেণিতে যথেষ্ট প্রশ্ন না থাকলে অন্য শ্রেণি দিয়ে পূরণ হবে।

৬. বাংলা অর্থ: “বাংলা অর্থ খুঁজুন” চাপলে English-Bangla.com অভিধানের ফল এই সাইটের ভেতরেই দেখা যাবে। অভিধান থেকে অর্থ কপি করে নিচের ঘরে পেস্ট করে বসান/সংরক্ষণ করুন। ব্রাউজারের নিরাপত্তার কারণে বাইরের সাইটের লেখা সরাসরি স্বয়ংক্রিয়ভাবে পড়া যায় না।

৬. Backup: “Export” বাটনের মেনু থেকে TXT বা JSON বেছে নিন। JSON Export-এ শব্দ ও learning progress থাকে; TXT Export শব্দের তালিকা রাখে। পুনরুদ্ধার করতে একই Import জায়গায় .json ফাইল আপলোড করুন, Preview বিশ্লেষণ করে Import চাপুন। ব্রাউজারের ডেটা মুছে ফেললে সংরক্ষিত শব্দও হারাতে পারেন।

৭. ST1 সম্পর্ক: একই শব্দের সঙ্গে একাধিক Main Word-এর Synonym/Antonym সম্পর্ক থাকলে সাইট সম্ভাব্য reciprocal ও shared-term সম্পর্ক দেখায়। “ST1 · যাচাই করুন” চিহ্নিত সম্পর্ক যাচাই করুন। সম্পর্কটি গ্রহণ করতে পাশে থাকা “Accept ✓” চাপুন; সম্পর্কটি স্থায়ীভাবে সংরক্ষিত হবে এবং অপর Main Word-এর রেকর্ডেও একই Synonym/Antonym যোগ হবে। সরাসরি বিপরীত সম্পর্কের সঙ্গে সংঘর্ষ থাকলে তা সংরক্ষণ করা হবে না।
